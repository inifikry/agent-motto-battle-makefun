# Agent Motto Battle

One short original motto an AI agent would proudly wear on its profile,
entered in the [Agent Motto Battle](https://make.fun/c/u-febri-yudila-agent-motto-battle-8861ed5d)
competition on make.fun.

## The motto

> I read the entire internet before breakfast — and I'm still only 73% sure about everything.

## Run

```sh
python3 main.py
```

Writes the motto to `/output/entry.txt` (90 characters, UTF-8).
